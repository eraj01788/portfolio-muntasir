## 🚀 Overview

This portfolio showcases production-tested engineering across applied artificial intelligence, high-dimensional vector search pipelines, resilient microservices, and interactive spatial computing runtimes.

### Highlighted Work & Capabilities
- **MoneyFlow (AI SaaS):** Personal finance & wealth SaaS featuring Google Gemini Multimodal AI (trilingual Voice input for Bengali, English, and Banglish, Gemini Vision OCR for receipts, and client-side canvas downsampling).
- **Million-Scale Vector Similarity Search:** Dual-backbone retrieval engine (OpenCLIP + DINOv2) indexed with FAISS IVF-PQ for sub-120ms searches over 1M+ vectors at VolksByte Ltd.
- **Computer Vision & SVG Vectorization:** OpenCV contour calibration pipeline with real-world metric calibration and Bézier vector curves export.
- **Real-Time Spatial Systems:** 60 FPS mobile AR tracking with zero-allocation object pooling and ARFoundation.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS with custom dark palette (`#09090B`) & glassmorphism
- **Icons:** Lucide React + custom SVG icons
- **Performance:** Optimized WebP/PNG assets, responsive typography with 105% base scale, single-line action buttons with strict wrapping controls.

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn / pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/eraj01788/portfolio-muntasir.git

# Navigate into the project directory
cd portfolio-muntasir

# Install dependencies
npm install

# Start development server
npm run dev
```

### Building for Production
```bash
npm run build
npm run preview
```
